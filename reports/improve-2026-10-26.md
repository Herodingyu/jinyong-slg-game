### 改前
`fightAttPose` 全武器共用一套动作时间轴（蓄力前倾 6°→出招前送 9°→带回冲），十把武器十套武功打出来身体动作**一模一样**，只有 `drawWeaponFx` 特效颜色形状不同。改前同时间戳截帧目验确认：dash/bullet/stab 在 1160ms 出招帧姿态完全一致——丁工那句"每一种招式动作是不一样的"直指此病。

### 改法

**身段层**：`fightAttPose` 改 `ATT_POSES` 分发表，9 个编舞函数（`attBase` 提供蓄力/快起/带回冲基础窗口，各函数叠加专属身段）：

| kind | 武功 | 身段设计 |
|------|------|---------|
| dash | 太祖长拳 | 两记快拳连打（第二拳冲量 65%），紧凑前倾小快灵 |
| sweep | 打狗棒/弯刀 | 先扭身后抡扫——蓄力期 lean **-9°**（反向拧身），挥出扫到 **+16°**，腿随转体大摆 |
| dragon | 降龙十八掌 | 全招式最深马步蓄力（squash 0.88、蓄力窗口更长），沉身双掌**前推 18°**，全身送掌 |
| wave | 空明拳 | 蓄力期云手慢摇（sin 摆），出招柔推慢进慢出，不僵直 |
| beam | 六脉/一阳指 | 蓄力后仰凝神、**头部几乎锁定**（瞄准感），出招速点即回 |
| bullet | 火枪 | 贴腮瞄准（头后仰），击发后整个人被**后坐力震仰 -13°**+重心后错半步 |
| stab | 匕首 | 深蹲蓄力→整个人**弹射前扑 20°**+大弓箭步后腿蹬直，全招式最凶 |
| smash | 狼牙棒/铁杖 | 抡起上挺拉伸（coil -7°）→俯身砸落 +15°，与整体跃起叠加 |
| slashx | 残谱一式 | 躯干一正一反**双快斩**（+10°→-12° 扭腰挥臂） |

`fightPartnerPose`（合体技接力）调的就是 `fightAttPose`，接力段自动继承专属身段。

**特效层**：`drawWeaponFx` 每 kind 强化（零素材程序绘制）——
- **dash**：出拳速度线三条短流光 + 守方处第二拳小爆（连打的"打"字落点）
- **sweep**：延迟尾弧两道（挥过的轨迹留风痕）+ 命中横斩冲击带
- **dragon**：掌风压地——守方脚下雪尘**双环涟漪**扩散
- **wave**：气浪环 4→6 + 环上**阴阳双游光点**反向流转（空明拳意）
- **beam**：**六脉神剑六道剑气扇形散开、各自错峰、收束汇聚爆光**（`data.js` 给 liumai 加 `beams:6`，今日唯一内容层改动）；一阳指保持单道粗光束 + 新增端点余辉不撒（指力透体）
- **bullet**：枪口星形焰（击发瞬间）+ 三团硝烟缓升
- **stab**：瞬闪**整条白芒**（一刺即到）+ 命中四尖星芒
- **smash**：八颗碎石确定性抛物线迸起再落回
- **slashx**：两道月牙剑气错峰飞出 + 第二斩反向小 X（双斩要斩得出"两次"）

**场景层**：stab/dash/slashx 出招窗攻方**双层渐淡残影**（身体"动出来"的速度感，stab 最凶双层）；dash 第二拳场景层一次性火花补爆+轻震。

## 自评：哪里还不像机战（苛刻模式）
1. **squash-stretch 是同一张立绘的 transform 形变**，不是真逐帧动作——零素材约束下的天花板，P1-9 已记账。横扫的"扭身"在 1024px 写实立绘上是整体倾斜+分层剪切，读得出意图，禁不起定格细抠。
2. **残影是半透明同图复制**，不是动作关键帧残像。SRW 的残影带色偏和形变，零素材下接受。
3. **各招式的"收势"仍共用 easeOutBack 回弹模板**——出招差异化做到了，收招差异化没做（9 套收势观众分不出）。若评审要求，可在 attBase 里给回弹加 per-kind 系数。
4. 六脉六道剑气在**会心**时宽度不分叉（crit 只加粗单道逻辑已随 beams>1 分支绕过）——低优先观察项。
5. 敌我质感落差（立绘 vs sprite）依旧，中期项已记账。
