# 标杆调研 · 机战A 战斗画面（丁工 2026-10-19 指定标尺）

> 丁工要求：对标 PSP 版《超级机器人大战A》的战斗画面——人物会动、左右分屏。

## 版本考据（调研结论）

- **GBA 原版机战A（2001）**：经典**左右分屏**战斗画面。攻方居左、守方居右，同屏对峙；双方都是逐帧 2D sprite 动画（待机呼吸/攻击动作分解/受击后仰/回避位移/击破爆炸），底部双方 HP 条+伤害数字。这一版就是"左右分屏+人物会动"的原始出处。
- **PSP《机战A PORTABLE》（2008-06-19）**：分辨率提升、部分角色重绘、加入配音；战斗动画大多流用 PS2《机战MX》引擎——**全屏剧场式**（攻/守方轮流占满全屏，非分屏），机体动作更复杂（多段攻击、变形、分身残影）。可加/关战斗动画，方块键切换 16:9/4:3。

**丁工要的标杆取两者交集**：双方同屏对峙 + 双方都有完整动作 + 底部双 HP 条 + 演出可跳过。

## 零素材约束下的逼近手段（程序动画，全部可做）

1. **立绘角度动画**：出招瞬间攻方立绘 rotate(-6°) 前倾，命中瞬间守方 rotate(+8°) 后仰回弹——canvas rotate 即可，零素材。
2. **受击颤动**：crit 时守方 3 帧内 x 抖动 ±6px 两次（现有 shake 只震镜头）。
3. **攻方收招回位**：lunge 结束后 1-2 帧后倾回弹（现在有回位曲线，可加过冲回弹 easeOutBack）。
4. **待机呼吸加强**：bob 振幅 2→4，频率按角色速度差异化（轻功高 = 浮动快）。
5. **演出跳过**：FIGHT 期间点击 canvas → endFight + 快进 log（机战 × 键同款体验）。
